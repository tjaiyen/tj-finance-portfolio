Milestone-Gated Capital Governance — Applied to a Public Case

A small, runnable dbt project modeling the finance disciplines a Finance Manager applies to a large hardware/capital program — milestone risk, cost escalation, capacity-vs-realized variance, and a make-vs-buy/TCO framework — case-study framing: Amazon's Amazon Leo satellite broadband program.

⚠ Not affiliated with, endorsed by, or built using any internal Amazon data. Every figure describing the real program below is sourced to public reporting, shown with its citation and an evidence-tier badge (see legend). Every figure describing an internal Amazon decision (make-vs-buy, variance drivers) is fully synthetic and marked illustrative. This is an independent analysis applying my own cost-accounting/FP&A methodology to a public case — not a claim of insider knowledge.
