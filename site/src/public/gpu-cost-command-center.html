1The ledger
FinOps · overhead absorption

Who actually pays for idle GPU capacity?

Shared inference cluster cost, split into an active pool (compute actually used) and an idle pool (provisioned but unused — the overhead), then absorbed across tenants by token share, exactly like a factory absorbs shared equipment cost across job orders by machine-hours. Every number below is a column produced and tested by dbt build — nothing is computed on this page.

The throughline Three chapters, one problem, at three different scales. Chapter 1 shows it in a single customer's bill — idle capacity, split by who used the cluster the most. Chapter 2 shows it in a single site's economics — the same idle capacity, reframed as depreciation running with nothing yet to show for it. Chapter 3 shows it across a fleet — the same clock, ticking on every site still ramping at once. Different scale, same math, every time it could be checked against a tested number, it was.
