FinOps · overhead absorption

Who actually pays for idle GPU capacity?

Shared inference cluster cost, split into an active pool (compute actually used) and an idle pool (provisioned but unused — the overhead), then absorbed across tenants by token share, exactly like a factory absorbs shared equipment cost across job orders by machine-hours. Every number below is a column produced and tested by dbt build — nothing is computed on this page.
